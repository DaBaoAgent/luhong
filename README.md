## 一句话人物卡

陆鸿，男，1979 年 4 月生，苏州吴江平望人，苏州市缘跃纸制品有限公司负责人，吴江区残联副主席，中共预备党员。

10 个月大时因中毒性脑炎留下脑瘫后遗症，求职屡遭羞辱后摆摊、开照相馆、办工厂逆袭，年营业额超 1400 万，48 名员工中 35 名是残疾人。《感动中国》2022 年度人物（颁奖词"人生贵自强"）、江苏省自强模范、中国好人。2025 年跨界创办苏州新芝动力科技，电动轮椅牵引头销量破 3000 台、海外单笔 1300 台。
